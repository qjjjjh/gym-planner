# Gym Planner · 今日训练

单页 SPA 健身训练计划应用，专为移动端设计。无构建、无依赖、无后端，一份 `index.html` 直接浏览器打开即用。

在线部署：https://37itql77xvjakenhb3u.traesite.cn

---

## ✨ 功能

- **部位选择**：首页两列卡片，点选或多选训练部位（胸 / 背 / 肩 / 手臂 / 腿 / 核心）
- **动作库**：按部位浏览内置动作，点 ✓ 勾选，误触不会取消
- **计划清单**：已选动作汇总，长按数字拖拽调序，可设置组数 / 次数 / 休息
- **热身环节**：正式训练前的热身阶段，进度条同一条，热身计时与正式训练打通
- **训练计时**：每组大计时居中显示，组间休息自动倒数
- **调整计划**：训练中随时调序，未开始的动作可被替换 / 重排
- **喝水提醒**：仅在休息页弹出，闪烁等待动作完成后进入休息
- **暂停训练**：X 按钮二级菜单 → 暂停页 → 恢复，暂停期间时长不计入
- **日历记录**：每次训练完成自动入日历，颜色按总时长显示强度
- **加练合并**：完成页「继续加练」可回到首页重新选部位，本次记录合并到当天日历，日历详情分开显示「第 1 轮 / 加练」两组明细
- **退出确认**：计时、进度、当前动作一目了然，支持继续 / 暂停 / 结束

## 🚀 快速开始

直接用浏览器打开 `index.html`，或者扔到任意静态服务器（Nginx、GitHub Pages、Vercel、TraeSite 等）。不需要 `npm install`，不需要构建。

```bash
# 本地起一个静态服务（可选）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 💾 数据存储

所有训练数据保存在浏览器 `localStorage` 的 `gym-plan-v2` 键下。

## 🛠 技术栈

- 原生 HTML / CSS / JavaScript，无框架无打包器
- IIFE 包裹，`show(screenId)` 切换 `section.screen.active`
- CSS 变量主题：`--bg #101214`、`--accent #C8F542`、`--card #1C1F23`
- 移动端优先，viewport-fit=cover，适配安全区
